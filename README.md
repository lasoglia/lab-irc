# Sito di Religione Cattolica

Sito personale per condividere con le classi slide, documenti, link e lezioni
interattive. Il sito è statico (gratuito su GitHub Pages) e i contenuti si
gestiscono da un pannello in italiano su `/admin`.

**Per metterlo online la prima volta, segui `GUIDA-AVVIO.md`.**

Struttura:
- `index.html` — la pagina pubblica del sito
- `admin/` — il pannello di gestione (Decap CMS)
- `data/` — i contenuti modificabili dal pannello
- `uploads/` — i file caricati (slide, PDF, immagini)
