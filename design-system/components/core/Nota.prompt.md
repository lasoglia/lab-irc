Amber callout for supplementary information, warnings, and privacy notices.

```jsx
<Nota icon="💡">
  Suggerimento: pensa al legame con «adamà», la terra.
</Nota>

<Nota icon="🔒">
  <strong>Privacy:</strong> i tuoi dati restano sui server europei e servono solo per questa verifica.
</Nota>

<Nota>
  L'anti-cheat è attivo: copia/incolla e tasto destro sono disattivati.
</Nota>
```

**Use for:** learning tips, privacy disclaimers, anti-cheat notices, form hints.

The left border is always `--lab-ambra`. Background is a low-opacity amber tint.
Omit `icon` if no leading glyph is needed.
