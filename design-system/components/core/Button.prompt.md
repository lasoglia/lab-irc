Pill button/link that reacts to the cursor (magnetic pull, light sweep, press). Use for every action and CTA.

```jsx
<Button variant="primary">Inizia il percorso →</Button>
<Button variant="ghost" size="sm">Annulla</Button>
<Button variant="gold">Consegna</Button>
<Button variant="solemn">Chi sono</Button>
```

- `primary` — violet→cyan gradient, light sweep on hover. One per view.
- `ghost` — outline, violet fill rises from the bottom.
- `gold` — amber, exam/featured actions.
- `solemn` — gold hairline, uppercase tracked label; for quiet, ceremonial links.
- Sizes: `md` (13/21 padding), `sm` (8/13). All Fibonacci.
