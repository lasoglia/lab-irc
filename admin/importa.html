Importazione rapida

Molte lezioni, una volta sola

Trascina qui le cartelle delle tue lezioni così come le tieni sul computer (unità → lezione → file). La tabella si compila da sola: controlli, correggi e pubblichi tutto con un clic. Niente più materiali uno alla volta.

1

Collegamento a GitHub

Serve una chiave personale di GitHub, una sola volta: resta salvata solo su questo computer, come la password del pannello.

Non collegato
Come si crea la chiave (5 minuti, una volta sola)
  1. Su GitHub, in alto a destra, apri la tua foto → Settings.
  2. In fondo al menu a sinistra: Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Nome: Lab IRC importazione. Scadenza: 1 anno. In Repository access scegli Only select repositories → lab-irc.
  4. In Permissions → Repository permissions metti Contents su Read and write. Nient'altro.
  5. Generate token, copia la chiave (inizia con github_pat_) e incollala qui sopra. GitHub la mostra una volta sola.

La chiave permette solo di scrivere file in questo sito. Puoi revocarla in qualsiasi momento dalla stessa pagina di GitHub.
